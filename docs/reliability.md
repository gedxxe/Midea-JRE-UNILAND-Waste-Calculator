# Bug review: v0.11.4-alpha

Reviewed on 2026-10-17. [Back to README](../README.md).

The audit traced table calculation, exact date/time sharing, import/export, draft recovery, account changes, saved reports and graph extraction. Regressions below were reproduced with synthetic data before fixes, then tested against the corrected code. This review is not a claim that all bugs or attacks have been eliminated.

| Reproduced problem                                                                                                                                                                                                              | Fix and boundary                                                                                                                                                                                                                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A clipboard request rejected after editing could replace the current preview with old output. After an account change, it could restore the previous account's report into the new workspace.                                   | Report/worksheet copy callbacks require the same copy generation, account lifetime, factory, mode and preview. Old callbacks do not change the page or announce success. Normal manual-copy fallback remains available when context is unchanged. An already-issued operating-system clipboard write is not cancellable by this page guard. |
| Tab recovery wrote readings and synchronization metadata separately. If only the first write succeeded, old metadata could mark unsynced readings as saved. Reload then preferred the older server copy and lost local changes. | One atomic storage value contains the workspace and tabRecovery metadata. Legacy split-key copies are treated conservatively until compared with the server. Concurrent newer server versions retain explicit conflict handling. Metadata stays out of API payloads and portable backups.                                                   |
| Floating-point comparison accepted a cumulative number fractionally greater than the documented maximum.                                                                                                                        | Validate the whole integer and fractional part exactly before Number conversion. Exact-boundary values remain valid; above-boundary inputs are rejected by the browser engine and report API.                                                                                                                                               |
| A saved draft whose response was lost could show a false conflict on reload when the server returned identical content with reordered JSON keys.                                                                                | Compare object content independently of key order. Preserve array order, exact reading strings, missing fields and extra collections as meaningful differences; genuine concurrent edits still require a choice.                                                                                                                            |

## Compatibility and verification

- No dependency, framework, SQL migration, meter factor, report grouping or historical recalculation changes.
- Workspace version 4, account storage keys, all three electricity modes, gas/Water entries and report revision links are preserved. Legacy tab recovery may show a conflict rather than silently dropping uncertain local changes.
- Tests reproduce delayed copy failures after edits and identity changes, partial browser-storage writes, legacy recovery with and without a concurrent server update, lost save responses with reordered JSON keys, and exact numeric boundaries. API integration checks rejected invalid reports create no stored record.
- The full quality gate remains required: source/format checks, selected secret-pattern scanning, dependency audit, unit tests, isolated PostgreSQL tests and desktop/mobile browser tests. Browser services are mocked for regression tests; live development and deployed build/time checks are separate evidence.

If storage rejects a complete write, the page cannot make that storage reliable. Keep a private backup and confirm server save status before closing. Code tags restore code, not database data. Previously unverified credential rotation, administrator MFA and restoration exercises remain prerequisites for a beta decision; see [security review](security.md).

PostgreSQL documents that [jsonb does not preserve object key order](https://www.postgresql.org/docs/16/datatype-json.html). A transport-order difference is not evidence of another operator changing a draft.
